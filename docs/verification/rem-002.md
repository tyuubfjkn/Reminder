## Implementation decisions and boundaries
- Keep manual protocol 1.0.0 and add optional assistant v1; older renderer fixtures remain usable. Callers must feature-detect the new capability.
- The local checkout is a verified text snapshot, not remote Git ancestry; GitHub base trees preserve existing binaries and provide canonical commits.
- Local sandbox temporary-directory rename returned EPERM. Unit tests use a dedicated scratch directory under this checkout as TEMP/TMP; production atomic file replacement remains unchanged and is checked on Windows CI.
- No new runtime dependencies, service deployment, credential bundling or automatic paid retries. Manual task operations stay independent of AI configuration/network errors.
- Schema v2 requires a closed-app pre-migration backup for rollback to a schema-v1 build. Never delete or silently downgrade user data.
- Complete REM-002 acceptance still requires reviewed frontend integration and actual credential-backed provider verification. Do not advance dependent reminder UI as though that acceptance were complete.
